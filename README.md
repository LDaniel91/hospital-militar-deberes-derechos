# Hospital Militar Dr. Joaquín Castillo Duany
## Portal de Deberes y Derechos de los Pacientes y Acompañantes

Sitio web informativo desarrollado para el **Hospital Militar "Dr. Joaquín Castillo Duany"** de Santiago de Cuba. Su objetivo es dar a conocer, de forma clara y accesible, los derechos y deberes de los pacientes y acompañantes, así como información institucional, galería y canales de contacto.

---

## 🚀 Características

- ✅ Diseño **responsive** adaptado a móviles, tablets y escritorio.
- 🌙 **Modo claro / oscuro** con persistencia en `localStorage`.
- 🗂️ **Pestañas (tabs)** para organizar Derechos y Deberes.
- 📂 **Acordeones** interactivos para cada artículo de la normativa.
- ✨ Animaciones de aparición al hacer scroll (**IntersectionObserver**).
- 🖼️ Galería institucional con efecto hover.
- 💬 Sección de testimonios.
- 📬 Formulario de contacto que abre el cliente de correo (`mailto:`).
- 📄 **Generación de PDF** con la normativa completa usando `jsPDF` + `jsPDF-AutoTable`.
- 🎨 Estilos centralizados mediante **variables CSS** (fácil personalización).
- 🧩 Código separado en HTML, CSS y JS (arquitectura limpia y mantenible).

---

## 🧱 Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| **HTML5** | Estructura semántica del sitio |
| **CSS3** | Variables, Grid, Flexbox, animaciones y transiciones |
| **JavaScript Vanilla (ES6+)** | Interactividad, tema oscuro, tabs, acordeones, PDF |
| **jsPDF 2.5.1** | Generación del documento PDF |
| **jsPDF-AutoTable 3.5.31** | Tablas automáticas dentro del PDF |
| **CDN Cloudflare** | Carga de las librerías PDF |

> No requiere frameworks ni proceso de compilación. Es un sitio **100 % estático**.
